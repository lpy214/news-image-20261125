A program that draws a 1024x1024 newspaper front page, "The World Today", summing up Wednesday 25 November 2026 in six verified stories: gunmen hold 25 hostages in a Cartagena supermarket after a botched armoured-truck robbery, the CIA and the director of national intelligence are hit by a hack of an unclassified system, a Houthi strike hits a Riyadh financial-district tower injuring 11, Xiamen Airlines orders 50 Boeing 737-8 jets for about $7.4 billion, Nvidia's Jensen Huang apologises to staff and says he is in therapy a day after his return as CEO, and California braces for near-record king tides as an atmospheric river hits Thanksgiving travel. Pure Python 3 standard library: it rasterises its own hand-drawn 5x7 bitmap font, draws every picture from shapes, and encodes the PNG by hand, so two runs write byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
